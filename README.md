# HYPO-Align
repository for hypo-align framework

# Run
- Please first update the config.py to add your own tokens or api key (huggingface, deepseek and openai).
- Run jailbreak.py to view LLM defense before and post HYPO-Align.
- The example is shown in Llama2-13b, you can change it to other models.
- Preloaded lens include Llama3.1-8b, Llama2-13b, Llama2-7b and Qwen2.5-7b. If you want to use any other models, please run lens_training.py and vector_generate.py first, and configure your own lens.
